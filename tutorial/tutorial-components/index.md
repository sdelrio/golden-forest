# Tutorial - Components

This section covers reusable UI components available in The Golden Forest.

## Available Components

- [Steps Component](./component-steps.md) — Sequential workflows with numbered indicators, states, and interactive mode
- [Card Component](./component-card.md) — Linkable content cards with icon support, grid layouts, and sub-components
- [DashboardCard Component](./component-dashboardcard.md) — Clickable dashboard cards with accent colors, tags, and hover effects
- [Accordion Component](./component-accordion.md) — Expandable/collapsible content sections with animated transitions
- [BarChart Component](./component-barchart.md) — Recharts-based bar charts with per-bar coloring and dark mode
