OWASP

The Open Web Application Security Project (OWASP) is a nonprofit foundation that improves software security through open, freely available resources: articles, methodologies, documentation, tools, and technologies. Since 2003 it has published the Top 10 project, a broad-consensus list of the most critical security risks facing organizations.

This article covers the four resources that matter most day to day: the Top 10, the Cheat Sheet Series, the ASVS, and the Proactive Controls.

OWASP Top 10​

The Top 10 is a standard awareness document for developers and web application security. The current release is Top 10:2025.

IDRiskFocus
A01:2025Broken Access ControlMissing or weak authorization checks
A02:2025Security MisconfigurationInsecure defaults, exposed services, verbose errors
A03:2025Software Supply Chain FailuresCompromised or unverified dependencies and build steps
A04:2025Cryptographic FailuresWeak or missing encryption at rest and in transit
A05:2025InjectionUntrusted data interpreted as code (SQL, OS, LDAP, XSS)
A06:2025Insecure DesignMissing threat modeling and secure design patterns
A07:2025Authentication FailuresWeak credential, session, and MFA handling
A08:2025Software or Data Integrity FailuresUnverified updates, deserialization, CI/CD integrity
A09:2025Security Logging and Alerting FailuresMissing detection and response signals
A10:2025Mishandling of Exceptional ConditionsPoor error and edge-case handling leaking or failing open
note

The 2021 edition is still widely referenced. The Cheat Sheet Series mapping index below is built around the 2021 categories, which remain useful as a checklist even after the 2025 reshuffle (SSRF folded into Broken Access Control, Supply Chain promoted to A03, and Mishandling of Exceptional Conditions added at A10).

There are domain-specific variants for other platforms:

  • OWASP Mobile Top 10

OWASP Cheat Sheet Series​

The Cheat Sheet Series is a concise collection of high-value guidance on specific application security topics, written by practitioners and maintained in the OWASP/CheatSheetSeries repository. Each cheat sheet is a self-contained reference for one topic, so it doubles as a review checklist.

The project organises its ~130 cheat sheets through four indices:

IndexPurpose
Top 10Maps each Top 10 category to its relevant cheat sheets
ASVSMaps cheat sheets to Application Security Verification Standard requirements
MASVSMaps cheat sheets to mobile application security requirements
Proactive ControlsMaps cheat sheets to the ten proactive security controls

Application Security Verification Standard (ASVS)​

The ASVS is a framework of security requirements used to design, build, and test applications. Version 5.0 is organised into 17 chapters:

  • V1 Encoding and Sanitization
  • V2 Validation and Business Logic
  • V3 Web Frontend Security
  • V4 API and Web Service
  • V5 File Handling
  • V6 Authentication
  • V7 Session Management
  • V8 Authorization
  • V9 Self-contained Tokens
  • V10 OAuth and OIDC
  • V11 Cryptography
  • V12 Secure Communication
  • V13 Configuration
  • V14 Data Protection
  • V15 Secure Coding and Architecture
  • V16 Security Logging and Error Handling
  • V17 WebRTC

Use the ASVS index to jump from a requirement chapter straight to the matching cheat sheets.

Proactive Controls​

The Proactive Controls are ten security techniques to include in every software project, ordered by importance. Control C1 is the most fundamental.

IDControl
C1Define Security Requirements
C2Leverage Security Frameworks and Libraries
C3Secure Database Access
C4Encode and Escape Data
C5Validate All Inputs
C6Implement Digital Identity
C7Enforce Access Controls
C8Protect Data Everywhere
C9Implement Security Logging and Monitoring
C10Handle All Errors and Exceptions

Notable Cheat Sheets​

A curated starting set from the series, grouped by concern.

Injection and Input​

Injection Prevention

Prevent untrusted data being interpreted as code across interpreters.

Cross Site Scripting Prevention

Context-aware output encoding rules for every HTML/JS/CSS sink.

SQL Injection Prevention

Parameterized queries and defense-in-depth for database access.

Input Validation

Allow-list validation and canonicalization strategies.

Identity and Access​

Authentication

Password storage, MFA, and account management controls.

Authorization

Enforce least privilege on every request, not just the UI.

Session Management

Session IDs, cookies, timeouts, and renewal.

Password Storage

Argon2id, scrypt, bcrypt, and migration guidance.

Data and Cryptography​

Cryptographic Storage

Algorithm selection and key handling for stored data.

Secrets Management

Storing, rotating, and auditing application secrets.

Transport Layer Security

TLS configuration, cipher suites, and HSTS.

Key Management

Key lifecycle, storage, rotation, and separation.

Configuration and Infrastructure​

Docker Security

Harden images, runtimes, and container networking.

Kubernetes Security

RBAC, network policy, secrets, and admission control.

Infrastructure as Code Security

Keep provisioning templates secure and reviewed.

Software Supply Chain Security

SBOMs, dependency pinning, and artifact integrity.

Process and Observability​

Threat Modeling

Find design flaws before writing code.

Secure Code Review

A structured approach to reviewing code for security.

Logging

What to log, what to redact, and how to protect logs.

Error Handling

Fail securely without leaking internals.

AI and LLM Systems​

LLM Prompt Injection Prevention

Defend against direct and indirect prompt injection.

AI Agent Security

Sandboxing, permissions, and tool-use boundaries for agents.

MCP Security

Securing Model Context Protocol servers and clients.

Secure Coding with AI

Using AI assistants without introducing new weak points.
